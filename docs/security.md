# 資料保護與稽核

DutyGrid 將本機 `dutygrid.db` 以 SQLCipher 加密。資料庫金鑰首次啟動時以隨機 256-bit 值產生，僅存放於目前作業系統帳號的憑證儲存區（macOS Keychain、Windows Credential Manager 或 Linux 相容 secret service）。金鑰不會寫入資料庫、設定檔、工作區 JSON 或稽核紀錄。

資料庫位置由應用程式管理，不支援使用者直接複製、重新命名或搬移 `dutygrid.db`。金鑰參照與資料庫位置綁定；搬移後程式會拒絕開啟，而不會嘗試猜測或複製金鑰。資料交接應使用受控的匯出／匯入流程。

首次升級時，既有明文資料庫會先轉存為加密暫存資料庫、驗證可開啟後再取代原檔。請在升級前依機關規範完成受控備份；若作業系統帳號或其憑證儲存區被清除，未配置機關復原金鑰的資料庫將無法復原。

應用程式會在本機資料目錄的 `logs/` 建立每日 audit log。每筆僅記錄時間、操作、資源類型、筆數與成功狀態，不記錄姓名、電話、檔案路徑、原始匯入內容或 SQL。這些紀錄用於本機營運追蹤，並非防竄改或集中式合規稽核證據。

目前已納入的人員資料相關事件包括人員清單讀取、匯入與清除、人員配置新增／修改／刪除，以及檔案匯出。機關版如需不可否認性、集中保存或多人權限，必須再導入簽章／集中稽核與 RBAC。
