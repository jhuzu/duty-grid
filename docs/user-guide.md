# DutyGrid 使用說明

DutyGrid（視窗名稱：勤務人力規劃系統）是 macOS 優先的桌面勤務部署規劃工具。它把勤務點位、路線、人員、裝備與部署表集中在同一個本機工作區，適合規劃道路警衛、活動維安或需要以地圖呈現崗哨的勤務。

本文件依目前程式實作撰寫。資料不會送往本專案自建伺服器；但地圖模式會連線下載底圖圖磚，詳見「已知限制」。

## 開始前

啟動後，輸入「勤務計畫名稱」，選擇下列其中一種模式，再按「新增勤務計畫」。

- **地圖模式**：以板橋警察分局附近為初始中心，使用線上地圖底圖，點位採經緯度。
- **自選底圖模式**：選擇 PNG、JPG、JPEG 或 WebP 圖片，再按「匯入至編輯區」。程式會複製該圖至應用程式資料夾，點位採 0–1000 的 XY 相對座標；介面建議底圖至少為 1600 × 900 像素。

已建立的計畫會保存在本機資料庫。重啟程式時會自動開啟最近更新的計畫；也可用「儲存工作區」輸出 `.dutygrid.json`，日後在「勤務計畫」頁按「開啟工作區」載入。

## 建議操作流程

```text
建立計畫 → 手繪路線 → 新增點位 → 匯入/配置人員
       → 補齊部署表與裝備 → 輸出地圖、PDF 或 Excel
```

### 1. 先建立手繪路線

在「路線」頁按「開始繪製」，逐點點擊地圖形成折線，按「完成繪製」，輸入路線名稱並保存。繪製時可按 Space、Delete 或 Backspace 移除最後一個折點，Escape 取消，Enter 結束繪製。此方式不需要先建立點位，適合先標示勤務動線，再補上崗哨。

### 2. 新增與管理點位

1. 開啟「點位」，選擇顏色、空心圓或號誌圖示。
2. 按「開始繪製」，在地圖或自選底圖按一下。
3. 在右側輸入點位編號與名稱，按保存。兩欄皆不可空白。
4. 點一下既有點位可選取；雙擊可改名稱；拖曳可移動。選取後按 Delete 或 Backspace 會開啟刪除確認。

刪除點位會由 SQLite 外鍵連帶移除相關人力配置與裝備。若點位正被路線使用，資料庫的 `RESTRICT` 約束可能拒絕刪除；請先移除相關路線或路線停靠點。

### 3. 補充：以點位序列建立路線

除了先畫手繪路線，也可輸入路線名稱、勾選至少兩個已建立點位，再保存成點位序列路線。這種路線會和點位建立關聯，因此可直接作為部署表的點位來源。

已選取路線可變更六種顏色及實線、虛線、實箭頭線或虛箭頭線；雙擊路線名稱可改名。亦可將選取路線存為「常用路線」，供其他計畫套用。常用路線儲存的是幾何座標，不會自動建立或關聯新的勤務點位。

### 4. 匯入與配置人員

在「人力配置」頁按「選擇人力檔案」匯入 `.csv` 或 `.xlsx`。欄位可用中文或英文名稱，必填為：

| 欄位 | 可接受欄名 |
| --- | --- |
| 員編 | `personnel_code`、`personnel-number`、`員編` |
| 無線電代號 | `radio_code`、`radio`、`無線電代號` |
| 姓名 | `name`、`姓名` |
| 職稱 | `title`、`職稱` |
| 所屬單位 | `unit`、`所屬單位` |
| 聯絡電話 | `phone`、`聯絡電話` |

標題列必須位於檔案前 10 列。CSV 支援 UTF-8（含 BOM）、Big5 與以雙引號包住的逗號欄位。資料列缺少任一必填值會被拒絕並記錄原因；員編或無線電代號與既有資料相同時更新既有人員；兩個代號分別指向不同人員時會拒絕該列，避免錯誤合併。

先在地圖點選勤務點位，再在右側搜尋、以單位/職稱篩選，並按「配置」。同一人員可配置在同一計畫的多個點位。頁面也會列出尚未配置的人員與最近一次匯入的拒絕列。按「讀取測試資料集」會從原始碼專案的 `data/` 找第一個 Excel 或 CSV（Excel 優先）；這是開發/原始碼環境功能，已安裝版本是否能使用須待確認。

### 5. 編輯部署表與裝備

「部署表」以所選路線的點位產生列，可：

- 選擇崗哨別、派遣單位、無線電代號與協調員電話。
- 加入其他地圖點位、移除列，或新增手動崗哨。
- 為點位或手動崗哨選取人員與裝備；裝備可套用內建的勤務組合。
- 點選表格列可在地圖定位點位。

點位的裝備會寫入資料庫。部署表中的崗哨別、單位、無線電、協調電話、手動崗哨及其人員/裝備主要保存在前端工作階段，只有透過「儲存工作區」輸出的 JSON 會包含部分工作區選項；詳見「已知限制」。

### 6. 匯出

- **部署表頁**：「匯出地圖 PNG」下載目前地圖；「匯出安全維護部署表」依 `標準化部署表.xlsx` 產生 Excel。範本最多填入 33 列（第 7–39 列）。
- **地圖輸出頁**：輸入標題、調整比例後可輸出橫向 A4 PNG 或單頁 PDF；輸出會加上路線圖例。地圖畫面設定為西向上，北向箭頭依目前方位旋轉。

若地圖尚未載入完成，請稍候後再輸出。輸出位置由 macOS 儲存對話框決定。

## 關閉與資料位置

直接關閉應用程式視窗即可。若要離開目前計畫，請在「勤務計畫」頁使用「退出勤務計畫」；此動作會清除該計畫的工作區快取，但不會刪除計畫、點位、路線、人員或裝備資料。

資料庫路徑由 Tauri 的 `app_local_data_dir()` 決定，檔名固定為 `dutygrid.db`。macOS 的實際目錄由系統與 bundle identifier 決定；正式版 identifier 為 `tw.gov.newtaipei.dutygrid`，開發版為 `tw.gov.newtaipei.dutygrid.development`。請以 Finder 顯示隱藏檔或從應用程式支援目錄確認實際位置，因程式未在 UI 顯示完整路徑（**待確認**）。自選底圖副本位於同一資料目錄下的 `custom-basemaps/`。

## 已知限制

- 沒有帳號、多人協作、伺服器同步或雲端備份功能。
- 「路線調整（未實作）」不是導覽列項目；程式雖保留條件分支，但目前使用者無法從介面開啟它。
- 地圖輸出中的「警力配置表」明確標註為待新增功能，內容目前是空白列。
- 自選底圖輸出的路線會繪製實線或虛線，但畫布實作沒有箭頭；與地圖模式的箭頭樣式不完全一致。
- 手繪路線本身不連結勤務點位；部署表匯出需要選取含點位的路線。先畫動線後，如需 Excel 部署表，仍須另建立點位序列路線，或確認部署表已加入足夠地圖點位。
- 點位新建時後端未驗證顏色、經緯度與 XY 範圍；編輯既有點位時才驗證。請使用介面提供的選項與有效座標。
- 開啟勤務計畫時，程式會還原資料庫中的工作區狀態。若要跨電腦或在重建資料庫後繼續工作，請使用「儲存工作區」保留可重開的設定。
